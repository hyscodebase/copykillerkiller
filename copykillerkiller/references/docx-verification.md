# DOCX 보존 및 검증

## 사본에 수정 적용

1. 사용자가 지정한 작업 대상의 경로와 SHA-256을 기록한다. 과거 보고서에 일치하는 판본이 따로 있으면 그 판본의 경로도 별도로 기록한다. 다른 폴더 또는 다른 이름으로 사본을 저장한다. 과제에서 파일명을 지정했다면 폴더를 달리해 이름을 유지할 수 있다.
2. 수정할 문단의 위치와 기존 문장을 확인한다. 앞쪽 문단이 추가·삭제되면 인덱스가 바뀌므로 위치와 문장을 함께 대조한다. 동일 문장이 여러 번 나오는 경우 앞뒤 문장과 절 제목을 쓴다.
3. 수정이 필요한 실행 구간의 텍스트만 바꾼다. 서식이 섞인 문단, 하이퍼링크, 수식, 각주 참조, 필드를 한 실행 구간으로 합치지 않는다. 단순한 문단도 문단 스타일과 속성을 유지한다. 전면 재생성은 사용자가 요구한 형식 변경에만 적용한다.

## Word 주석 사본 만들기

사용자가 사본을 요청한 경우에 실행한다. 보고서를 전처리했다면 지정한 `target_assessment.draft_index`에 해당하는 DOCX와 `drafts`의 SHA-256을 사용한다. 보고서 없이 검토한다면 사용자가 지정한 DOCX의 경로와 직접 계산한 SHA-256을 사용한다. 어느 경우든 현재 작업 대상에서 문단을 확인하고 다음 형식으로 메모를 준비한다. 이 파일은 원고의 발췌를 담으므로 로컬 작업 폴더에 둔다.

```json
[
  {
    "paragraph": 1,
    "expected_text": "가상 원고의 첫 문단 전체 텍스트.",
    "comment": "이 판단을 뒷받침하는 자료는 어디에 있나요?"
  }
]
```

`paragraph`는 표 내부를 제외한 본문 직속 문단의 1부터 시작하는 번호다. 빈 문단도 번호에 포함한다. `expected_text`는 현재 문단의 Word 텍스트(`w:t`)를 순서대로 이은 전체 문구다. 앞뒤 공백도 포함하며 보고서에서 복사한 문구나 표시 시작점으로 대신하지 않는다.

```sh
python3 "<스킬 폴더>/scripts/create_review_copy.py" "현재 원고.docx" --expected-sha256 "<작업 대상 SHA-256>" --notes "주석.json" --out "검토용 주석 사본.docx"
```

해시가 달라졌거나 문단이 일치하지 않으면 현재 원고를 다시 확인한다. 저장 경로에 파일이 이미 있으면 새 이름을 정한다. 오류를 피하려고 검사 당시 판본이나 해시로 바꾸지 않는다.

기존 주석이 있는 문서에는 주석을 보존할 수 있는 편집 도구를 사용한다. 그런 도구를 사용할 수 없으면 위치별 검토 의견을 제공한다.

## 결과 확인

수정 사본을 만든 뒤 아래 명령으로 내부 파일과 보호 요소를 비교한다. `<스킬 폴더>`에는 현재 읽고 있는 `SKILL.md`가 들어 있는 경로를 넣는다.

```sh
python3 "<스킬 폴더>/scripts/verify_docx.py" "원본.docx" "검토용 사본.docx"
```

결과의 `source.sha256`을 편집 전에 기록한 작업 대상 해시와 대조한다. `main_body_text_changed`는 주석과 서식을 제외한 본문 문단의 저장 텍스트와 수식 텍스트를 비교한다. 값이 `false`이고 추가한 것이 주석뿐이면 결과물을 **검토용 주석 사본**으로 안내한다. 사용자가 요청해 과거 판본을 재현했다면 **과거 판본 재현용**이라고 별도로 표시한다. 검사 결과는 검사 당시 파일에 연결한다.

`zip_parts`에서 변경된 내부 파일을, `protected_document_xml`에서 표·수식·구역·링크·필드 등의 변화 여부를 확인한다. 변화가 있다면 요청한 수정으로 설명되는지 확인한다. 본문 인용의 의미와 화면 배치는 아래 절차로 별도 확인한다.

- 결과 DOCX가 열리는지 확인하고, 수정 전후 본문을 대조해 요청된 변경만 들어갔는지 확인한다.
- 서식 보존이 필요한 작업에서는 DOCX 내부 파일의 차이를 점검한다. 표, 수식, 구역, 목차 필드, 링크, 참고문헌, 각주, 고지문 중 해당 요소를 비교한다. 변경된 항목의 개수뿐 아니라 필요한 내용과 참조도 확인한다. 주석 전용 결과에서는 주석 앵커를 제외한 본문이 같은지 확인한다.
- 최종 DOCX를 렌더해 전체 페이지의 한글 글꼴, 줄바꿈, 페이지 넘김, 표·수식 배치와 잘림을 확인한다. 이전에 검토한 렌더와 이미지가 같은 페이지는 그 비교로 확인할 수 있다. 렌더가 불가능하거나 대체 글꼴을 사용했다면 확인한 범위를 결과에 적는다.
- PDF도 요청받았다면 검증한 최종 DOCX에서 내보내고 해당 PDF의 페이지와 텍스트를 확인한다. 이전 렌더를 새 결과로 전달하지 않는다.

작업 로그에 원고나 검사보고서의 개인정보가 남을 수 있다. 예제나 배포용 스킬에 원본, 실제 검사번호, 개인 경로, 발췌문을 포함하지 않는다.
